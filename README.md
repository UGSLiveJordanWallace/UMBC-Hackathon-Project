# Getting Started
This is a quick and easy way to get started with the front and back end of the project. If there are any issues, please add them to the github issues sections within this repository.

## Prerequisites
Node v22+
Git

## Installation
### Cloning the Repo
You can get the project started by cloning the repository with the information below
```console
git clone https://github.com/UGSLiveJordanWallace/UMBC-Hackathon-Project.git
```

### Downloading from Github
You can also download the Zip file of both the development and server branches and extract them separately

## Environment
### Client
Run `npm install` to install all the packages required by the project

### Server
Run `pip install -r requirements.txt` to install all libraries required by the project

## Up and Running
### Client
Run `npm run dev` to start a localhost server. This can be accessed in the browser by navigating to the localhost:<port> address

### Server
#### Activating virtual environment
Run `source Scripts/activate` within the root directory of your project. This will start the virtual environment needed to run the server with the needed packages.
#### Running the script
Run `python FlaskProject.py` to start the flask server.
